# 换电脑测试 · 转移说明

> 结论：**代码要同步，数据要单独导出**。两者是分开的，拷了文件夹不等于带走数据。

## 一、代码怎么带

两种方式任选：

| 方式 | 做法 |
|---|---|
| 压缩包（推荐） | 拷 `D:\WorkBuddy\Apps\zupu-system-便携包.zip`（约 57KB，已含 index.html + src + docs），微信/网盘/U盘传回家 |
| 直接拷文件夹 | 整个 `D:\WorkBuddy\Apps\zupu-system` 目录复制走 |

到家后：解压到任意目录 → **双击 `index.html`** 即可，无需安装任何东西、断网也能用。

⚠️ 不要把 `index.html` 单独拎出来（它需要同级的 `src` 目录），必须整个文件夹一起。

## 二、数据怎么带

系统数据存在**这台电脑、这个浏览器**的本地数据库（IndexedDB）里，**不会跟着文件夹走**。

| 情况 | 要不要带数据 |
|---|---|
| 你只看了示例数据，没录真实内容 | **不用带**。家里首次打开就是自带的示例数据（42 人 / 6 世代） |
| 你在公司录了真实数据想在家里接着看 | **要带**：数据管理 → 「导出备份」→ 存成 JSON → 带回家 → 数据管理 → 「导入备份」 |

家里如果想回到干净的示例状态：数据管理 → 「恢复示例数据」。

## 三、三个容易踩的坑

1. **换浏览器 = 换数据库**。公司用 Edge、家里用 Chrome 打开，数据不通。建议固定用同一个浏览器。
2. **别用无痕 / InPrivate 模式**打开。无痕窗口关闭时，录入的数据会被清空。
3. **数据只在这台机器的这个浏览器里**。清浏览器数据（缓存/站点数据）也会一并清掉，所以每次正式录入前先导出一份 JSON 备份。

4. §十 多房支场景（42 人 / 3 房支 / 6 世代）
