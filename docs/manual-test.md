> 适用版本：v1.2（含字段级实时校验、世次联动；种子数据 3 房支 / 6 世代）
> 打开方式：双击 `index.html`。随时可在「数据管理 → 恢复示例数据」重置到初始 42 人。
> 标记说明：🔴 错误级 = 红色提示，**阻断保存**；🟡 提醒级 = 橙色提示，**不阻断**，确认无误可继续保存。

## 已知边界（非 bug，属设计取舍）

- 提醒级不阻断保存：宗谱数据常有特例（如失考年份、非常规世次），确认无误可直接保存。
- 简介与备注参与全局检索：搜人名可能命中"备注里提到此人"的其他成员，列表行内会显示备注原文便于辨认。
- 字辈不做强校验（定稿决策）；在世/已故不做视觉区分，仅生卒年属性体现。
- 「生育逻辑」未校验：如父去世年早于子女出生年这类跨字段矛盾，暂不检测（列入后续迭代候选）。
